# Package index

## Colonization-extinction models from a meta-web

- [`metaWebNetAssembly()`](https://lsaravia.github.io/meweasmo/reference/metaWebNetAssembly.md)
  : Simulation of an Assembly process from a Meta-web (discrete time)
- [`metaWebNetAssemblyCT()`](https://lsaravia.github.io/meweasmo/reference/metaWebNetAssemblyCT.md)
  : Simulation of an Assembly process from a Meta-web (continuous time)

## Multilayer (trophic and non-trophic) assembly

- [`metaWebNetAssemblyML()`](https://lsaravia.github.io/meweasmo/reference/metaWebNetAssemblyML.md)
  : Simulation of an assembly process from a multilayer meta-web
- [`build_multilayer_assembly()`](https://lsaravia.github.io/meweasmo/reference/build_multilayer_assembly.md)
  : Matrices of the multilayer assembly model
- [`default_layer_signs()`](https://lsaravia.github.io/meweasmo/reference/default_layer_signs.md)
  : Default signs of the interaction layers
- [`metaWebNetAssemblyMLCT()`](https://lsaravia.github.io/meweasmo/reference/metaWebNetAssemblyMLCT.md)
  : Simulation of an assembly process from a multilayer meta-web: C++
  core

## Generalized Lotka-Volterra models

- [`metaWebNetAssemblyGLV()`](https://lsaravia.github.io/meweasmo/reference/metaWebNetAssemblyGLV.md)
  : Simulation of an Assembly process from a Meta-web with stochastic
  Generalized Lotka-Volterra dynamics
- [`generateGLVparmsFromAdj()`](https://lsaravia.github.io/meweasmo/reference/generateGLVparmsFromAdj.md)
  : Generate random parameters of a generalized Lotka-Volterra model
  from an adjacency matrix
- [`generateGLVparmsFromAdjR()`](https://lsaravia.github.io/meweasmo/reference/generateGLVparmsFromAdjR.md)
  : R implementation of generateGLVparmsFromAdj
- [`generateRandomGLVadjMat()`](https://lsaravia.github.io/meweasmo/reference/generateRandomGLVadjMat.md)
  : Generate random Lotka-Volterra adjacency matrix with a given
  proportion of interactions (approximately)
- [`calcPropInteractionsGLVadjMat()`](https://lsaravia.github.io/meweasmo/reference/calcPropInteractionsGLVadjMat.md)
  : Calculate the proportion of interactions types in a Lotka-Volterra
  adjacency matrix
